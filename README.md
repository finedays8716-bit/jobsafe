# 부모님을 지켜주는 안전 약속

인천광역시 유아교육진흥원 안전교육 디지털 자료

## 소개
유치원 유아(만 3~5세)를 대상으로 한 일터 안전 교육 웹 프로그램입니다.
부모님의 직업과 안전 도구를 연결하며 일터 안전의 중요성을 배웁니다.

## 구성
1. **이야기나누기** — 일터 위험 상황과 안전 메시지 슬라이드
2. **도구 연결하기** — 직업과 안전 도구를 드래그·탭으로 매칭하는 게임
3. **메모리 게임** — 카드를 뒤집어 직업과 안전 도구 짝을 찾는 게임

## 대상
- 유치원 만 3~5세
- 전자칠판 및 태블릿 환경 모두 지원

## 사용 방법
별도 설치 없이 브라우저에서 바로 실행됩니다.
`img/` 폴더의 이미지 파일과 함께 사용하세요.
